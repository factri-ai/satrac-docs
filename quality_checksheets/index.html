    Quality Checksheets Module User Guide

    Date: 22-09-2025
    Contact: support@factri.ai

    1. Introduction

    This document outlines the guidelines for using the DataWiz application in the Bangalore and Chennai plants for the Quality Checksheets use case.

    2. Installation and Login

    The application URL is https://satrac.datawiz.app. Chrome is the recommended browser.

    For mobile app installation, please refer this section.

    3. Open Quality Checksheets for a SF Number

    1. Scan the SF number QR code and come to the order details page
    2. Click on the Quality Checksheets button at the bottom of the page after scrolling
    3. Initialize the checksheets if not done already
    4. You will see all the mapped Quality Checksheets for the part family the SF number belongs to

    Initiate Checksheets for the First Time

    4. Fill and Submit the Checksheet Form

    1. Open the required Quality Checksheet by clicking on it's name
    2. Fill out all the necessary details. If required the users can change the language of the form fields to Hindi from English
    3. After the checksheet is filled, enter the submitter and approver name and submit the form
    4. The status of the form will get updated

    Save the Filled Checksheet for Draft

    Submit the Checksheet

    5. Print the Checksheet Form

    1. Open the submitted checksheet form
    2. Review all the filled details
    3. If everything is fine, fill the approver name and approve the form
    4. The status of the form will get updated
